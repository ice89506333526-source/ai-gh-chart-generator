# AI Guitar Hero Chart Generator — из MP3 в играбельную песню Guitar Hero III

Программа берёт mp3 (лучше всего — соло-гитара или фингерстайл-кавер) и за ~1 минуту
делает готовый пакет для Guitar Hero III PC: ноты Expert и Hard, аудио, секции
для тренировки. Вся математика (темп, транскрипция, фильтры шума, маппинг на лады)
выполняется автоматически; от человека нужны выбор файла и две контрольные
проверки на слух.

---

## Часть 0. Что где лежит

| Что | Где |
|---|---|
| **Программа (exe)** | `D:\ai-gh\pipeline\dist\AI-GH-Chart-Generator.exe` (~420 МБ, один файл) |
| Готовые пакеты для игры | `D:\ai-gh\pipeline\out\<ID>\` |
| Проверочные аудио (превью) | `D:\ai-gh\pipeline\work\<ID>\` |
| Запасной запуск без exe (консоль) | `D:\ai-gh\pipeline\make_song.bat` |
| Настройки сложности | `D:\ai-gh\pipeline\config.json` |

Важно: exe можно скопировать куда угодно (он самодостаточный), но результаты
всегда складываются в `D:\ai-gh\pipeline\out`.

Первый запуск exe может занять 10–30 секунд (самораспаковка) и вызвать
предупреждение Windows SmartScreen («Неизвестный издатель») — это нормально
для самодельной программы. Нажми «Подробнее» → «Выполнить в любом случае».
Если антивирус долго «думает» при первом запуске — просто подожди, файл
проверяется, это одноразовая задержка.

## Часть 1. Конвертация песни (в программе)

Запусти `AI-GH-Chart-Generator.exe`. Порядок действий — по блокам окна сверху вниз:

1. **«1. Песня»**
   - Нажми **«Открыть…»** и выбери mp3/wav/flac/ogg.
   - Введи **ID песни** — короткое имя латиницей, без пробелов (например
     `smутноевремя` нельзя, а `smutnoe` — можно). Этот же ID потом используется
     в GHTCP, так что выбирай осмысленный: `gorod`, `aria2` и т.п.
   - **Название** и **Исполнитель** — необязательно; это то, что будет написано
     в меню игры.
2. **«2. Настройки (обычно не нужны)»** — оставь как есть:
   - «Темп BPM» пустой = темп подбирается автоматически;
   - «Сделать легче» — уменьшает плотность нот (галочку ставь только если
     после игры в чарт окажется слишком тяжело);
   - «Добавить дорожку Hard» — включена по умолчанию;
   - **«Это песня с вокалом (отделить гитару)»** — включай для полноценных
     песен (Lumen, 25/17 и т.п.): ноты строятся по гитарному стему без вокала,
     поэтому вокал больше не «просачивается» в чарт. Аудио в игре остаётся
     оригинальной песней (с вокалом). Отнимает 1–3 минуты на видеокарте.
3. Нажми **«3. Конвертировать»**. Внизу в журнале будет видно, что происходит:
   сетка → транскрипция → фильтры → маппинг → ревизия → экспорт. Обычно это
   40–90 секунд на 4-минутную песню.
4. **«4. Проверка и результат»** — когда появится «Готово»:
   - **«▶ Прослушать: клики темпа»** — откроется трек с щелчками метронома.
     Клики должны совпадать с пульсом песни на всём протяжении.
   - **«▶ Прослушать: найденные ноты»** — «синтезаторная» версия распознанных
     нот. Мелодия должна узнаваться, без писка и глухих лишних ударов.
   - Если превью хороши → **«✔ Подтвердить»** (программа запишет подтверждение).
   - Если что-то не так → исправь настройки (шаг 2) и снова «Конвертировать».
5. **«Открыть папку для GHTCP»** — откроет папку с готовым пакетом.

Результат в `D:\ai-gh\pipeline\out\<ID>\`:

| Файл | Что это |
|---|---|
| `notes.chart` | ноты Expert + Hard — именно его импортируем в игру |
| `song.wav` | аудио для игры (уже с тишиной в начале и конце) |
| `chart_export_report.json` | статистика: ноты, sustains, Star Power |
| `CHECKLIST.md` | короткая памятка |

Кнопка **«♥ Поблагодарить автора»** (правый нижний угол) открывает окно
с реквизитами: карта Озон (для РФ) и USDT в сети TON (для остального мира),
с QR-кодом для сканирования кошельком.

## Часть 2. Импорт в Guitar Hero III (GHTCP)

Программа готовит файлы; в игру их добавляет **GHTCP 2.0.4** (установлен
отдельно от игры). Порядок — тот же, которым добавлялись `aighstage0`,
`aighgorod1` и остальные:

1. Открой GHTCP.
2. **File → Open Game Settings** — GHTCP должен показать список песен GH3.
   (Если список пустой или ошибка — проверь, что путь к игре указан в GHTCP
   правильно. ❓ *Точные названия пунктов меню GHTCP допиши здесь вручную —
   у меня нет скриншотов программы.*)
3. Создай **новую песню** (Add/New song) с параметрами:
   - **Song ID** — ровно тот же ID, что ты вводил в программе (например `gorod`);
   - Name / Artist — как хочется видеть в игре;
   - **Chart / Notes file** — `D:\ai-gh\pipeline\out\<ID>\notes.chart`;
   - **Audio** — `D:\ai-gh\pipeline\out\<ID>\song.wav`.
   ❓ *Как в GHTCP называется поле для chart и для аудио в твоей версии, и
   какие галочки (например про sustains/HOPO) ты выставлял — допиши вручную,
   если отличаются от привычных тебе.*
4. Сохрани/примени песню. GHTCP перезапишет игровые паки
   (резервные копии `qb.pak.xen.backup` уже существуют с самого начала проекта).
5. Запусти Guitar Hero III и найди песню в списке.
   ❓ *В каком разделе меню появляется кастомная песня (основной список/бонусные) —
   допиши вручную по факту.*
6. Играй на **Expert** (основная сложность) или **Hard** (4 лады, ровнее и легче).

> Перед первым импортом новой песни полезно убедиться, что старые импорты
> живы: запусти игру и проверь, что предыдущая кастомная песня на месте.

## Часть 3. В игре: тренировка и сложные места

- **Пауза → Practice**: доступны скорости 50/75/100% и отдельные секции
  `Part 01…NN` (примерно по 14–15 секунд) + Lead-in и Tail. Сложное место ищи
  по номеру секции, где сыпешься.
- Если после практики какие-то Part всё равно непроходимы:
  - в программе поставь галочку **«Сделать легче»** и переконвертируй,
  - или в консольном bat-режиме используй `--min-gap 0.114` (ещё легче) /
    `0.06` (плотнее).
  После переконвертации **импортируй chart в GHTCP заново** — старый заменится.

## Часть 4. Если что-то не так

| Симптом | Что делать |
|---|---|
| Клики в превью «плывут» или попадают не в пульс | В настройках укажи **BPM вручную** (если знаешь темп) и переконвертируй. Если сбивается сама точка отсчёта — скажи мне, поправлю `--grid-start`. |
| В нотах писк / глухие удары | Скажи таймкоды — поправлю фильтры в `config.json`. |
| Конвертирую песню с вокалом, а в нотах «каша» от голоса | Включи галочку **«Это песня с вокалом (отделить гитару)»** и переконвертируй. |
| Ошибка «Не найдено окружение Demucs…» | Отделение гитары использует `D:\ai-gh\ai-gh-stage2\.venv` — на этой машине оно есть; на других компьютерах без него работает только режим чистой гитары (без галочки). |
| Слишком тяжело / легко | Галочка «Сделать легче» или `--min-gap` (см. Часть 3). |
| «Конвертация не удалась: validation failed» | Пришли мне текст из журнала — программа блокирует битые чарты сама, это защита. |
| Программа не открывает превью в плеере | Открой файлы руками: `D:\ai-gh\pipeline\work\<ID>\grid_preview.wav` и `notes_preview.wav`. |
| Windows блокирует exe | «Подробнее» → «Выполнить в любом случае» (см. Часть 0). |
| Игра не видит новую песню | Проверь, что в GHTCP песня сохранена (Apply/Save) и ID в игре совпадает. ❓ детали допиши вручную. |

## Часть 5. Запасные способы запуска (без exe)

**Консольный интерактивный режим** — двойной клик по `make_song.bat`,
перетащить mp3 в окно, через пробел дописать ID, Enter:

```
"D:\music\песня.mp3" mysong
```

**Прямой вызов со всеми опциями:**

```
D:\ai-gh\ai-gh-stage3\.venv\Scripts\python.exe D:\ai-gh\pipeline\make_song.py "D:\music\песня.mp3" --id mysong --name "Название" --artist "Исполнитель" --bpm 132 --min-gap 0.114 --no-hard
```

GUI из исходников (для разработки):

```
D:\ai-gh\ai-gh-stage3\.venv\Scripts\python.exe D:\ai-gh\pipeline\gh3_maker_gui.py
```

Пересборка exe (после правок GUI):

```
cd D:\ai-gh\pipeline
D:\ai-gh\ai-gh-stage3\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile --windowed --name "AI-GH-Chart-Generator" --add-data "donation_qr.jpg;." --add-data "ton_qr.png;." --add-data "config.json;." --collect-data basic_pitch --hidden-import basic_pitch.inference gh3_maker_gui.py --distpath dist --workpath build --specpath .
```

## Технические детали

- Конвейер: `make_song.py` (10 фаз), параметры — `config.json`. Эталон сложности:
  `D:\ai-gh\ai-gh-stage4\DIFFICULTY_REFERENCE.md` (≈850 событий на 4 минуты,
  аккорды ≤2, никаких интервалов <80 мс, SP каждые 64 бита, практика-секции 32 бита).
- Маппинг Expert — **контурный** (окно 8 событий): лады повторяют движение
  мелодии, как на Hard, но плотнее и с аккордами. Ноты за концом музыки
  (тихий хвост) обрезаются автоматически.
- Микс при сепарации: гитара ×1.5, вокал ×0.6, остальное без изменений —
  гитара звучит на переднем плане.
- Транскрипция: Basic Pitch ICASSP 2022 напрямую по mp3 (без разделения стемов —
  подход для соло/фингерстайла). Для полноценных песен с барабанами/басом
  понадобится Stage 2 (Demucs) — отдельная задача.
- Внутри exe: Python 3.11, TensorFlow (движок Basic Pitch), librosa, Tkinter.
- Ограничение текущей версии: если рядом с exe лежит `config.json`, программа
  читает его (можно править параметры сложности), иначе использует встроенный.
